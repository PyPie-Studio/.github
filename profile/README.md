### 📡 NodeRadar Pro

**Enterprise-Grade Network Observability & Asset Discovery**

[![C#](https://img.shields.io/badge/C%23-.NET_10-512BD4?style=flat-square&logo=dotnet&logoColor=white)](#)
[![Avalonia UI](https://img.shields.io/badge/Avalonia_UI-12.1-8B44AC?style=flat-square)](#)
[![NativeAOT](https://img.shields.io/badge/NativeAOT-Compiled-00C853?style=flat-square)](#)
[![License](https://img.shields.io/badge/License-Freeware-blue?style=flat-square)](#)

[**⬇️ Download**](https://github.com/PyPie-Studio/NodeRadar-Pro) &nbsp;·&nbsp; [**📖 Repository**](https://github.com/PyPie-Studio/NodeRadar-Pro)

</div>

A low-latency network reconnaissance and monitoring suite built for IT professionals. Discover every device on your LAN in seconds, track uptime with millisecond precision, and detect unauthorized connections in real time — all from a single native binary with zero installation overhead.

- 🔍 **Subnet Sweeping** — Multi-threaded ARP + ICMP discovery with heuristic OS fingerprinting (MAC OUI, mDNS, SSDP, open ports)
- 🛰️ **Live Topology Mapping** — Interactive sonar-style radar visualization of all connected assets and their states
- 🚨 **Intrusion Sentinel** — Background watchdog alerting on unrecognized MAC addresses connecting to the network
- 📊 **Telemetry Engine** — Real-time ICMP latency, jitter analysis, packet loss tracking, and uptime history
- 🔐 **Encrypted Local Storage** — LiteDB with AES-256 encryption; absolutely zero data leaves the machine
- ⚡ **NativeAOT Binary** — Sub-second cold start, low memory footprint, no .NET runtime installation required

### 🛡️ unslop-windows

**Safe-Tier Windows 11 Debloater, Telemetry Neutralizer & Privacy Hardener**

[![PowerShell](https://img.shields.io/badge/PowerShell-5.1_&_7+-5391FE?style=flat-square&logo=powershell&logoColor=white)](#)
[![Windows 11](https://img.shields.io/badge/Windows_11-23H2_|_24H2_|_25H2+-0078D4?style=flat-square&logo=windows11&logoColor=white)](#)
[![MIT License](https://img.shields.io/badge/License-MIT-green?style=flat-square)](#)
[![CI](https://img.shields.io/github/actions/workflow/status/PyPie-Studio/unslop-windows/ci.yml?style=flat-square&label=Quality%20Gate)](#)

[**⬇️ Download**](https://github.com/PyPie-Studio/unslop-windows/releases) &nbsp;·&nbsp; [**📖 Repository**](https://github.com/PyPie-Studio/unslop-windows) &nbsp;·&nbsp; [**📋 Changelog**](https://github.com/PyPie-Studio/unslop-windows/blob/main/CHANGELOG.md)

</div>

The only Windows debloater that **guarantees zero broken updates**. 18 modular stages neutralize Copilot, Recall AI, telemetry, Cortana, widgets, and bloatware — while strictly protecting the component store, Windows Update pipeline, Microsoft Store, and critical runtimes.

- 🧹 **18 Hardening Modules** — Copilot, Recall snapshots, Cortana, Bing Search, diagnostic telemetry, background apps, Start menu ads, and 40+ bloatware packages
- ↩️ **100% Symmetrical `-Undo`** — Every single registry key, service, and scheduled task change is fully reversible in one command
- 👁️ **Non-Elevated `-DryRun`** — Complete read-only audit without admin rights — see exactly what will change before committing
- 🎮 **Smart Presets** — Gamer mode (keeps Xbox/gaming services), Productivity mode (keeps OneDrive/To-Do), or fully custom toggles
- 🧪 **7-Pillar Quality Gate** — AST validation, PSScriptAnalyzer, CRLF integrity, Pester test suite, and CI enforcement
- 🔒 **Zero Binaries, Zero Cloud** — Pure PowerShell + Batch. No compiled executables, no downloads, no network calls
